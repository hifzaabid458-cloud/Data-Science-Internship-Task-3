# Customer Segmentation Data Science Internship – Task 3

This repository contains Task 3 completed as part of the Online Retail Data Science Internship.

The project focuses on analyzing online retail customer transaction data and extracting meaningful customer insights using data preprocessing, exploratory data analysis, RFM analysis, and customer segmentation.

## 📂 Project

Customer Segmentation using RFM Analysis

The project analyzes customer purchasing behavior using the following RFM metrics:

- Recency – How recently a customer made a purchase
- Frequency – How often a customer made purchases
- Monetary – How much a customer spent

These metrics are used to understand customer behavior and group customers into meaningful segments.

## 🔍 Main Activities

- Dataset loading and exploration
- Data cleaning and preprocessing
- Handling missing and invalid records
- Exploratory Data Analysis (EDA)
- RFM feature calculation
- Customer behavior analysis
- Customer segmentation using clustering
- Segment comparison and interpretation
- Visualization of customer segments
- Business-oriented insights and recommendations

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📊 Key Analysis Areas

The project examines:

- Customer purchasing behavior
- Recency, Frequency, and Monetary values
- Customer spending patterns
- Customer segment characteristics
- High-value and low-value customer groups
- Differences between customer segments

## 🎯 Objective

The main objective of this project is to use data science and machine learning techniques to understand customer behavior and create meaningful customer segments.

The insights can help businesses develop more targeted marketing strategies, improve customer retention, and identify high-value customers.
